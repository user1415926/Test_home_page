# Audio Waveform Visualizer

WordPress plugin that renders eight waveform tracks, lets you upload or pick audio, highlight regions, and build a playback scenario with individual speed and zoom per track.

## Features

- eight WaveSurfer.js tracks with drag-to-select regions and per-track controls;
- audio input either from the WordPress media library or by uploading a local file directly on the page;
- adjustable zoom (px/sec) and playback speed for every track, plus quick reset;
- region playback uses the current track speed so you can audition edits in slow/fast motion;
- scenario panel where each command stores track, region, start offset, and speed (commands can be played or removed individually).

## Installation

1. Copy `audio-waveform-visualizer` into `wp-content/plugins/`.
2. Activate **Audio Waveform Visualizer** in the WordPress admin panel.

## Usage

Place the shortcode into a page or post:

```
[audio_waveform]
```

Optional: set the waveform height (pixels):

```
[audio_waveform height="220"]
```

### Tracks (top panel)

- **Select audio** ? pick a file from the media library (requires `wp_enqueue_media`).
- **Upload file** ? choose a local file; the waveform loads instantly without opening the library.
- Drag across the waveform to create a region (regions can be resized later).
- Use the zoom slider and speed field to fine-tune visuals and playback for each track.
- Buttons: `Play`, `Stop`, `Play region`, `Clear regions`, `Add command`.

### Command panel (bottom)

- Shows the list of commands with track name, region, speed, and start offset.
- Play or remove each command individually, or run the entire scenario.
- The text area mirrors the list so you can copy the script.
